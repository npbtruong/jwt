Ba luồng đăng nhập: Session, JWT & OAuth2

Cùng một mục tiêu — biết “ai đang gọi” — nhưng ba cơ chế lưu trạng thái khác hẳn nhau. Đọc từng làn theo số thứ tự để thấy dữ liệu di chuyển giữa các bên như thế nào.

Client — trình duyệt / Vue app Backend — server Laravel Store — nơi lưu session (DB/Redis) Provider — bên thứ ba (Google…)
web.php · mặc định

Session + Cookie

STATEFUL · server nhớ
  1. Client → Backend Gửi email + mật khẩu qua form đăng nhập.
  2. Backend → Store Kiểm tra đúng, tạo một session và lưu vào DB/Redis kèm một session ID.
  3. Backend → Client Trả về cookie chứa session ID. Trình duyệt tự lưu.
  4. Client → Backend Mỗi request sau, trình duyệt tự đính cookie — bạn không phải làm gì.
  5. Backend → Store Tra session ID trong store để biết user là ai, rồi trả dữ liệu.

Mấu chốt: trạng thái nằm ở server. Đăng xuất = xoá session trong store. Vướng khi khác domain (cookie khó chia sẻ).

api.php · microservice

JWT (Token)

STATELESS · server quên
  1. Client → Backend Gửi email + mật khẩu tới endpoint /api/login.
  2. Backend Kiểm tra đúng, ký một JWT (có chữ ký) — không lưu gì ở server.
  3. Backend → Client Trả JWT về. Vue tự lưu (memory / localStorage).
  4. Client → Backend Mỗi request tự đính token: Authorization: Bearer <jwt>.
  5. Backend Verify chữ ký ngay tại chỗ (không tra DB) — hợp lệ thì biết ngay user là ai.

Mấu chốt: trạng thái nằm trong token. Mỗi service tự verify, không cần store chung — hợp domain độc lập / microservice.

giao thức uỷ quyền

OAuth2

GOOGLE LÀM CHỨNG · rồi như JWT
  1. Vue → Google Bấm “Đăng nhập bằng Google” — chuyển hướng sang Google.
  2. Google ↔ User Google hỏi, user đồng ý cho phép xem thông tin.
  3. Google → Backend Gửi ID token — làm chứng “đúng là ông A”.
  4. Backend Tin Google → tự phát token RIÊNG của app, không dùng token của Google.
  5. Backend → Vue Trả token-của-app. Vue lưu lại, đính Bearer cho các lần sau. → từ đây giống hệt làn JWT

Mấu chốt: Google chỉ làm chứng danh tính ở khúc đầu. Token bạn dùng về sau là của app tự phát — nên OAuth2 = “JWT + bước xác thực nhờ bên thứ ba”.

Session + Cookie

Chọn khi → Vue & Laravel cùng domain. Đơn giản, an toàn với cookie HttpOnly, đăng xuất dễ.

JWT

Chọn khi → domain độc lập, nhiều service tự verify token, app mobile. Đúng tinh thần stateless.

OAuth2

Chọn khi → cần cho user đăng nhập bằng tài khoản bên thứ ba, hoặc cấp quyền cho app ngoài.
Session & JWT trả lời “giữ trạng thái ở đâu”. OAuth2 trả lời “ai được phép cấp token” — khác tầng, không mâu thuẫn.
